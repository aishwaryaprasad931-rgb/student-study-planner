📚 Student Study Planner

A clean and responsive Student Study Planner website built using HTML and CSS.

The project is designed to help students organize their subjects, view study schedules, and track their academic progress through a simple and user-friendly interface.

✨ Features

- 📊 Today's progress dashboard
- 📚 Subject-wise progress tracking
- 🗓️ Daily study schedule
- 📈 Overall progress section
- 🎯 Weekly study goals
- 💡 Motivational section
- 📱 Responsive design for mobile and desktop
- 🎨 Clean and modern user interface

🛠️ Technologies Used

- HTML5
- CSS3

📂 Project Structure

student-study-planner/
│
├── index.html
├── style.css
└── README.md

🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in any web browser.
4. The website will run locally.
